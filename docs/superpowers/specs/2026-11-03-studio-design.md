# Thani's cinematic studio

User selected: take the creative lead and build the cinematic studio. This authorizes design decisions and implementation without further design questions.

Intent: a memorable developer portfolio that makes Thani's real work easy to explore. Preserve Nuxt 3, Vue and Three.js, project URLs, resume, experience and contact information. Work in the chat workspace; original Downloads project remains intact. Local preview only; keep existing deployment configuration.

Approaches: polish the existing house (least change, weaker connection to software); abstract sculpture (fast, less personal); interactive studio (selected, directly connects the scene to real projects).

Design: ink #132238, midnight #0d182a, porcelain #f0eee8, muted blue #9eafc3, apricot #f4b185, sky #8fb7de. Space Grotesk display, Inter body. Large left-aligned headline and quiet navigation; handcrafted Three.js cutaway studio on the right. Warm window, pale timber desk, illuminated project monitors, shelves, books, plants, chair and rug. Screens link to work; drag rotates the room; lighting and motion controls have explicit labels. No forced audio.

Normal document scrolling reveals substantial project features, concise about/skills, existing experience, and contact. Content stays usable if WebGL fails. Small screens stack text and scene. Reduced motion disables idle movement. Canvas resources, listeners and animation frames are disposed on unmount.

Verification: build, browser desktop/mobile inspection, navigation, lighting, motion, project selection, contact, reduced-motion and graceful WebGL fallback. No invented experience or metrics.
